# Community Code of Conduct

Q-Seed welcomes careful technical disagreement and evidence-based critique.
Participants are expected to be respectful, specific, and constructive.

Harassment, threats, discrimination, deliberate exposure of private
information, and sustained disruptive behavior are not acceptable. Project
maintainers may edit or remove contributions and restrict participation when
necessary to protect the community.

Report security issues through the private process in `SECURITY.md`. Report
other conduct concerns privately to the repository maintainers through their
GitHub profiles. Good-faith reports will be handled as confidentially as
practical.
